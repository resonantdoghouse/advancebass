## Practice Tips

This exercise teaches you two things at once: the name of each open string (E, A, D, G)
and the note at the 5th fret directly above it (A, D, G, C).

**How to practise:**

- Start at 60 BPM with a metronome — the tempo is deliberately slow so you can focus on clean tone
- Use alternating fingers (index and middle) throughout
- Let each note ring for its full half-note value before moving
- Section A–D ascends string by string; sections E–H descend back down — learn both directions

**Key fretboard facts to memorise:**

| String | Open | 5th fret |
|--------|------|----------|
| E (4th) | E | A |
| A (3rd) | A | D |
| D (2nd) | D | G |
| G (1st) | G | C |

Once this feels comfortable, try calling out the note name aloud as you play each one.
